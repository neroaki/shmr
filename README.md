# 서울역사박물관 리뉴얼

서울역사박물관의 전시와 소장자료를 이미지·타이포그래피·스크롤 인터랙션으로 소개하는 디자인 포트폴리오입니다. PC 중심의 단일 페이지로 제작했으며, 공식 운영 사이트가 아닙니다.

## 기술

React · TypeScript · Vite · SCSS · Lenis · Vercel

## 구성

- 히어로: 기록 사진과 키네틱 타이포그래피
- 주요 전시품: 4점의 전시품을 소개하는 가로 패널
- 기획전시·프로그램: 포스터 5개와 확장형 상세 화면
- 소장자료: 유물 10점의 그리드와 상세 화면
- 박물관 소개: 관람안내·교육·아카이브·행사 안내

라이트·다크 테마와 한국어·일본어를 지원합니다. 기본값은 라이트 테마·한국어이며, 관람·예약 등 상세 정보는 공식 사이트로 연결됩니다.

## 실행

Node.js 24 기준입니다.

```bash
npm ci
npm run dev
```

검증: `npm run lint` · `npm test` · `npm run build`
