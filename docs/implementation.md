## 주요 전시품 — 개요 + 겹침 섹션 (2026-10-25 재분석)

### 확인한 레퍼런스 구조

[Bureau Alexandra Jubé](https://bureau-alexandrajube.com/)의 실제 DOM·공개 JavaScript·스크롤 위치별 화면을 재확인.

- `ExpertiseOverview`: 분야 제목·소개와 전체 항목을 요약하는 개요. `ExpertisePanels` 상세 구간과 별개 컴포넌트.
- `ExpertisePanels`: 개별 `.js-panel`을 같은 sticky 화면 안에 absolute로 겹쳐 배치. 다음 패널은 xPercent 100→0, 앞 패널은 0→-10으로 이동. 단일 flex 트랙을 모두 같은 거리만큼 미는 슬라이더가 아님.
- 상세 구간의 큰 제목, 번호, 설명·관련 항목 위계를 확인. 1440×900에서 상세 제목 140px, 내부 article 약 610px, 바깥 장면 900px. 참고 수치이며 구현값으로 그대로 전용하지 않음.
- 스크롤에 scrub으로 진행을 연결하며 원본에는 blur(8px)가 있음. 이번 구현은 이미지 감상을 위해 blur를 제외. 좁거나 낮은 화면도 사용자 합의에 따라 같은 가로 겹침을 유지하고 패널 내부만 반응형으로 조정.

### 이번 적용 — 최신 정정이 우선

1. `#featured`는 **개요 1장 + 전시품 6장 = 7개 레이어를 가진 단일 호라이즌탈 구간**. 개요를 별도의 세로 섹션으로 두지 않음. ‘주요 전시품’ 제목과 6점의 목록도 첫 번째 레이어에 포함.
2. 같은 고정 장면에서 첫 전시품이 오른쪽에서 들어와 개요를 덮고, 이후 전시품이 한 장씩 앞 장 위에 쌓임. 순서는 도성대지도 → 서유견문 → 전차 381호 → 경성전차안내 → 서초삼호아파트 → 서울올림픽 성화봉. 전시품마다 실제 section·고유 ID·제목 제공.
3. **너비·높이·내용 길이에 따라 전체를 세로 목록으로 전환하는 분기 제거.** 이전의 1024px/700px/내용 높이 조건은 합의에 맞지 않아 폐기. 모바일과 낮은 화면에서도 같은 수평 겹침 구조 유지. 반응형은 패널 내부 글자·여백·이미지 배치만 조정.
4. 화면 y 위치는 개요부터 마지막 전시품까지 유지. 마지막 전시품 뒤에만 기존 감속 공식을 거쳐 다음 세로 섹션으로 이동. 휠·터치의 페이지 스크롤 진행을 수평 위치로 연결.
5. 이미지 원비율과 해상도 제한 유지. 가려진 패널 inert/aria-hidden, 현재 패널의 정보만 탐색 가능. 개요의 목록 버튼·이전/다음·오른쪽 ‘목록 ↖’ 복귀 버튼 제공. 복귀 버튼은 밑줄 경계와 포인터/키보드 포커스를 가진 44px 높이의 텍스트형 버튼이며 첫 레이어로 부드럽게 이동. 상단 왼쪽은 ‘주요 전시품’ 안내 텍스트로 유지. 키보드 목록 선택은 해당 제목으로 이동.
6. reduced-motion에서도 세로 목록으로 바꾸지 않음. 패널 이동 보간을 줄이고 완전한 장면 단위로 전환. 극단적으로 작은 화면이나 확대 글꼴에서는 패널 내부 내용만 스크롤 가능하게 해 읽기 접근성 유지. 검증한 일반 화면 크기에서는 내부 세로 넘침 없음.
7. 현재 위치는 첫 장에서 ‘목록’, 전시품 장면에서 ‘01 / 06’부터 ‘06 / 06’까지 표시. 새 가로 트랙이나 별도 개요 세로 구간을 추가하지 말 것.

### 유지한 스크롤과 디자인 조정

- Lenis `lerp: 0.12`, `smoothWheel: true`, `anchors: true`, `syncTouch: false`, `respectReducedMotion: true` 유지.
- `createHighlightsScroll`의 감속·세로 이탈 공식 유지. 마지막 진입은 완만하게 감속하고, 이후 세로 상승이 0→1 속도로 연결됨. 시간 기반 정지나 입력 잠금 없음.
- 설명 열 `clamp(272px,25vw,384px)`, 패널 padding `clamp(24px,3vw,48px)`, 이미지/설명 gap `clamp(32px,4vw,80px)` 유지.
- 개요 제목 `clamp(56px,8vw,128px)`, 상세 제목 `clamp(32px,3.6vw,64px)`, Pretendard 400. 한글 위계를 유지하면서 레퍼런스의 영문 세리프를 억지로 번역·적용하지 않음.
- 짝수 패널 바탕 `--highlights-surface-alternate: #242424`: 겹치는 경계를 읽기 위한 차콜 톤 차이. 레퍼런스 실측 색이 아닌 사용자 정정을 반영한 temporary 값. 기존 바탕·글자색·이미지에는 변화 없음.
- 이전 `scrollLeft` 기반 가로 트랙 구현은 제거. 개요를 포함한 7개 레이어의 단일 호라이즌탈 스택이 최신 기준. 이전의 별도 개요 세로 구간과 작은 화면 세로 대체는 폐기.

### 검증

Chrome 1440×900, 1440×650, 1024×650, 900×700, 768×900, 390×844, 390×650, 1920×1080에서 7개 레이어가 같은 y 좌표에 놓이는지 확인. 모든 크기에서 개요→첫 전시품 수평 겹침, 내부 세로 넘침 없음, 마지막 장 뒤의 완만한 세로 이탈 및 역방향 복귀 확인. 실제 휠 입력 시 수평 위치만 변하는지, 목록/버튼/키보드 이동, reduced-motion의 수평 구조 유지 확인. 낮은 데스크톱과 모바일 캡처 검토. 실제 기기·Safari 검증은 별도.

상단 메뉴 앵커 보정(2026-10-25): 기존 `html`의 scroll-padding이 헤더 높이보다 32px 컸고, 기본 앵커 이동과 Lenis 처리가 함께 실행될 수 있었음. 모바일에서는 접힌 메뉴의 높이와 주요 전시품 sticky 구간의 재측정으로 목적지 문서 위치가 추가로 변했음. scroll-padding을 헤더 높이로 맞추고 GNB는 기본 이동을 막아 한 번만 이동. 모바일 메뉴가 닫히고 레이아웃 재측정이 끝난 뒤 실제 헤더 높이로 목표 위치를 계산. 페이지 끝의 박물관 소개도 헤더 아래에 맞도록 푸터 하단 여백을 24px 늘림. Chrome 1440×900, 390×844에서 GNB 4개 목적지가 헤더 하단 ±1.5px 이내에 정렬되고 클릭 직후 급격한 점프가 없는지 확인.
