# 전시·행사·교육 카드 자료 수집

확인일: 2026-10-28 (한국 시간)

후속 구현 상태: 같은 날 로컬 검토본에서 기존 전시 3건과 화이트 버드·소리, 내것이 되는 순간을 연결해 5장 갤러리 및 상세 모달로 구성. 아래 수집 단계의 기록과 구분하며 나머지 후보 데이터는 보존. GitHub/Vercel 반영 없음.

## 범위와 결과

- 공식 메인 페이지의 `#edu_slider`(행사·교육) 10건을 확인. 앞 6건의 공식 상세 페이지를 열어 일정·대상·장소를 대조하고, 5건의 공식 포스터 원본 확보.
- 기존 기획전시 3건 + 추가 사용 준비 4건 = **7개 카드 분량**. 해금교실 1건은 확인 필요 예비 후보로 별도 분리.
- `src/data/programme-candidates.ts`에 기존 필드(id, number, title, description, dates, place, image, width, height, alt, source)를 유지하고 category, cta, time, audience, dateNote, imageNote를 필요한 경우에만 추가.
- 수집 및 다음 구현용 데이터 준비 단계. 기존 `ExhibitionProgramme` 화면의 3개 항목·배치·모션과 메뉴명은 변경하지 않음. 새 배열을 화면에 연결하거나 배포하지 않음.

## 일정·분류 확인사항

- **화이트 버드:** 제6회 상영은 10월 29일 14시, 13시 30분 입장 시작. 12세 이상. 무료이며 공식 안내는 사전 신청 또는 현장 접수 방식. 잔여석은 확인하지 않았으므로 예약 가능 표시 금지. 포스터는 미나리·화이트 버드·넘버원 3회 통합 안내이며 카드 일정에 다른 회차를 혼합하지 않음.
- **우리소리 토크콘서트:** 공연 성격이 있지만 공식 사이트의 교육예약/성인 게시물로 분류되어 카드 category는 교육. 시민 누구나, 선착순 25명이라는 모집 조건만 확인했으며 현재 잔여 인원은 미확인.
- **경희궁 탐험대:** 초등학교 1–6학년 자녀 동반 가족. 공식 본문 이미지에서 서울역사박물관 1학습실 사전 교육 및 경희궁 일대 탐험 확인. 총 10회이며 9월 26일·10월 3일 미운영. 회차별 모집기간을 전체 교육기간과 혼동하지 않음.
- **Visit Museum:** 성인 외국인 단체 교육. 외국인 대상이지만 한국어 진행이므로 영어 진행으로 소개하지 않음. 별도 통역 동반은 사전 협의. 상설전시/경희궁 관람과 만들기 활동 중 주제 선택. 교육기간은 본문·첨부 공통 4월 1일–12월 31일. 모집 시작일은 상단/본문 3월 10일과 첨부 3월 9일이 달라 카드에서 생략. 교육일은 단체별 협의이며 회차 소진 시 조기 마감 가능.
- **해금교실(예비):** 상단은 11월 3일–13일, 본문은 1기 11월 3–7일 / 2기 11월 10–14일. 종료일과 세부 장소를 확정하지 않고 `programmeReserve`에만 보관.
- ‘한가위 한마당 — 오색 한가위’는 9월 26일 종료된 행사로 현재 추천 묶음에서 제외. 3·4월 세뮤 예올, 상반기 경희궁 자료도 기간상 제외. ‘느낌있는 박물관’은 추가 탐색 후보이며 상세 검증·이미지 확보 미실시.

## 다음 화면 개편에서 지킬 기준

- 전시·행사·교육은 같은 시각 양식을 공유하되 분류를 정확히 표기. 모든 카드를 ‘기획전시’라고 표기하지 않음.
- 전체 섹션 명칭은 ‘전시·프로그램’ 또는 ‘전시·행사·교육’처럼 확장 범위를 드러내는 명칭 검토 필요. 이번 수집 작업에서는 명칭을 확정하거나 메뉴를 변경하지 않음.
- 준비 데이터 7건은 콘텐츠 수량이며 화면에 7건 연결되었다는 뜻이 아님. 다음 구현 시 배열 연결과 category/cta 출력 함께 적용.
- 이전에 철회한 포스터·타이포 독립 시차 연출을 이번 수집을 근거로 복구하지 않음.
- 기준일은 수집일이며 지속적인 예약 상태 보장이나 운영 데이터 자동 갱신 기능을 포함하지 않음.
