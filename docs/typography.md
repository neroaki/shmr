# Typography system

2026-11-02 · 공통 역할 시스템의 로컬 구현 (기존 7개 역할 + 보조 설명 support)

## 적용 기준

- 제목·도입·UI: 한국어·영어 SUITE Light 300, 일본어 Noto Sans JP Light 300. 본문·보조 정보: 한국어·영어 Pretendard Light 300, 일본어 Noto Sans JP Light 300.
- 각 언어가 같은 역할·크기·행간·자간을 공유하며 글꼴만 교체한다.
- 영어로 고정된 히어로 타이틀·About the Museum은 일본어 화면에서도 SUITE 사용. 영어 사진 설명은 Pretendard 사용.
- 글꼴은 저장소의 `src/assets/fonts`에서 로드한다. 운영체제 글꼴이나 외부 CDN에 의존하지 않는다.
- 일본어 파일: Google Fonts 공식 Noto Sans JP 배포본의 wght=300을 WOFF2로 변환. 전체 문자 집합 유지, 파일 크기 2,253,144 bytes. 원본 출처 https://github.com/google/fonts/tree/main/ofl/notosansjp · 동봉 NotoSansJP-OFL.txt.
- 기존 폰트 원본은 보존하되 런타임 CSS에서 사용하지 않는 서체를 선언하지 않는다.

## 역할과 스케일

기본 브라우저 글자 크기 16px일 때의 CSS 픽셀 기준. 물리 해상도·OS 배율·devicePixelRatio를 별도 배수로 곱하지 않는다. rem을 통해 사용자 기본 글자 크기와 확대 설정을 존중한다.

| 역할 | 1920px 폭 | 3840px 폭 | 행간 | 자간 | 사용 |
| --- | --- | --- | --- | --- | --- |
| display | 174.72 | 349.44 | 1.08 | -0.02em | 영어 히어로 타이틀, 9.1vw |
| section | 48 | 48 | 1.2 | -0.015em | 네 메인 섹션 제목, 방문 주소 |
| content | 24 | 24 | 1.3 | -0.01em | 개별 전시품·모달·정보 화면 제목 |
| lead | 18 | 18 | 1.6 | 0 | 도입 문장, 카드의 짧은 안내 제목, 사이트명 |
| body | 16 | 16 | 1.65 | 0 | 본문·설명·목록 |
| support | 14 | 14 | 1.65 | 0 | 소개 문장을 구체적으로 풀이하는 보조 설명 |
| meta | 12 | 12 | 1.5 | 0 | 연도·분류·출처·캡션·히어로 장식 문구 |
| ui | 14 | 14 | 1.5 | 0 | 메뉴·버튼·링크·닫기 |

section/content/lead/body/support/meta/ui는 화면 폭과 무관하게 동일한 rem 크기를 유지한다. 영어 히어로 display만 기존 유동 크기를 유지한다. 본문 16px, 보조 설명 14px, 캡션·장식 12px는 별도 위계이며 서로 합치지 않는다.

## 구현 방법

- `src/styles/_tokens.scss`: 글꼴과 각 역할의 크기·행간·자간·공통 굵기.
- `src/styles/_typography.scss`: `@include type.role(section)` 등 완전한 역할을 적용하는 공통 믹스인.
- 각 SCSS 끝의 Semantic typography 블록: 화면 요소와 역할의 대응. 개별 수치는 선언하지 않는다.
- `src/components/inline-card-detail.scss`: 두 갤러리가 공유하는 모달 타이포와 내부 배치. 전시별 제목/본문 크기 덮어쓰기 제거.
- 주요 전시품의 0.7 배율, 제목 이동 중 글자 크기 보간, 본문을 포함한 scale(.87), 소장자료 모달 전체 scale(.8), 내용에 따른 zoom 축소 제거.
- 기존 87% 전시품 구성과 80% 모달 외곽 크기는 실제 컨테이너 치수로 유지. 이미지 자체의 승인된 90%/80% 축소와 포스터 원근 모션은 유지.
- 뷰포트 높이 1000px 이하에서는 공통 media query로 내부 여백을 줄인다. 폰트 축소·텍스트 누락·스크롤로 해결하지 않는다.
- 일본어 모달은 일본어 줄바꿈 규칙을 적용한다.

## 의도된 예외

히어로의 작은 박물관 이름만 `History`의 r 왼쪽부터 y 오른쪽까지 실제 글자 폭을 측정하여 크기를 정한다. 기존 사용자가 지정한 타이틀 조형을 유지하기 위한 예외이며 일반 UI에 재사용하지 않는다. 언어 전환·글꼴 로딩 완료·리사이즈 시 다시 정렬한다.

Figma 보드의 #444 배경은 문서 표시용이며 앱 테마 색상에는 적용하지 않는다.

## 검증 결과

- 1600×900, 1920×1080, 3840×2160 CSS 뷰포트에서 한국어·일본어 화면 확인.
- 소장자료 10개 및 기획전시 5개 모달을 언어·뷰포트별로 열어 총 90개 조합 확인. 본문 영역 초과, 가로 넘침, 출처 겹침 없음.
- 네 메인 섹션 제목은 일반 PC와 4K에서 모두 48px 기준을 사용한다.
- 실제 브라우저에 저장소의 SUITE, Pretendard 및 Noto Sans JP가 로드됨. 히어로의 영어 타이틀은 SUITE 유지.
- 빌드, ESLint, git diff --check 통과. 로컬만 반영.
- 히어로는 1280·1680·1920·3840px 폭에서 사진·캡션 비겹침 확인. 캡션을 24px로 확대하는 스트레스 검사에서도 간격 유지. 일반 모션의 인트로 정착도 확인.

## 전체 섹션 본문·보조 정보 통일 — 2026-11-02

- 주요 전시품에서 확인한 본문·보조 정보 규칙을 히어로, 기획전시·프로그램, 소장자료, 박물관 소개, 두 모달 및 푸터로 확장.
- body는 16px / 1.65, meta는 12px / 1.5로 구분한다. 둘 다 Light 300이며 화면별로 값을 중복 선언하지 않는다. 이전 16px 통일 실험은 폐기한다.
- 제목·도입 문장·버튼은 기존 역할과 서체를 유지하되 크기는 위 표의 최신 기준을 따른다.
- 기존 PretendardVariable.woff2를 사용한다. 일본어 본문은 Noto Sans JP를 우선해 한자·가나의 서체가 섞이지 않도록 하며 같은 크기·굵기·행간을 적용한다.
- 공통 role 믹스인이 body/support/meta에 --font-reading을 선택하고 나머지 역할은 --font-family를 사용한다. support는 UI와 크기만 같고 읽기 서체·행간을 별도로 유지한다.
- 목록 분류의 접힘 높이는 고정 픽셀 대신 실제 한 줄 높이(lh)를 사용해 글자가 잘리지 않도록 한다.
- 기획전시·소장자료 모달의 텍스트 영역 상단 패딩만 기존의 1.5배. 짧은 화면에서는 16→24px, 나머지 화면에서는 각 갤러리의 기존 패딩에 1.5 적용. 이미지 및 나머지 방향 여백 유지.

## 히어로 캡션 배치

- 사진과 캡션은 같은 그리드의 인접 칸을 사용한다. 사진 슬롯은 width: 100%, min-width: 0, align-self: start로 자기 칸 폭과 원본 비율을 유지한다.
- 캡션이 커져 행 높이가 증가해도 사진 폭이 함께 늘어나 옆 칸을 침범하지 않는다. 캡션 위치를 글자 크기에 맞춰 임의 좌표로 옮기지 않는다.
- 질문을 포함한 장식 문구 전체에 meta 12px를 적용한다. 인트로의 사진 정착 후 나타나는 타이밍은 유지한다.

## 보조 설명 및 모달 간격

- 주요 전시품의 ‘한양의 지도와 새로운 문물을 담은 책…’ 문장은 support 14px / 1.65 / Light 300 적용. 도입 18px, 본문 16px, 캡션 12px는 유지한다.
- 두 갤러리의 공통 모달은 분류→제목 및 제목→본문→상세 정보→링크 사이를 공통 gap으로 관리한다. 일반 화면에서 24–48px(2.8svh), 높이 1000px 이하에서는 20px.
- 상세 정보의 행 간격은 일반 화면 10px, 짧은 화면 8px. 글자 크기나 사진 크기를 바꾸지 않고 텍스트 묶음 사이의 여백을 확장한다.
